# Motion Patterns

面向 React 与 Next.js 的生产级界面动效 Agent Skill，涵盖：

- 页面转场与退出动画
- 按钮、弹窗和 Toast 反馈
- 列表交错动画
- 滚动触发与滚动进度
- 布局动画与共享元素转场
- 动效性能与无障碍约束

## 安装

将本仓库克隆到 Cursor 的个人 Skills 目录：

```bash
git clone https://github.com/FFFOOOGGG/motion-patterns.git ~/.cursor/skills/motion-patterns
```

也可以把 `SKILL.md` 放到项目内的 `.cursor/skills/motion-patterns/`。

## 使用

在 Cursor 中提出 React、Next.js、Motion 页面转场或界面动效需求时使用此 Skill。

## 说明

示例依赖 `motion/react`，并假设项目已提供 `motionTokens`、`springs` 和 reduced-motion 辅助方法。
